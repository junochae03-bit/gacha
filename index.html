Gemini API 키 ● 완전 무료
기기에만 저장됩니다 (localStorage). 외부 전송 없음.
💡 Gemini API 키 발급 방법 (무료 · 신용카드 불필요)
  1. aistudio.google.com/apikey 접속 (구글 계정으로 로그인)
  2. Create API key 버튼 클릭
  3. 키 복사 (AIza...로 시작) → 위 칸에 붙여넣기 → 저장
  4. ✅ 완전 무료 (Gemini 2.5 Flash · 일 1,500회 무료)
✅ 허용 출처: 호요버스/넥슨/쿠로게임즈 등 개발사 공식 홈페이지, 공식 트위터/X, 공식 유튜브, 게임 내 공지
🚫 제외 출처: 나무위키, 위키백과, 디시인사이드, 루리웹, 인벤, 아카라이브, 개인 블로그, 유저 가이드 사이트
Gemini API 키 저장 후 게임과 검색 유형을 선택해 검색하세요.

☁️ GitHub Gist 동기화

💡 PC ↔ 모바일 데이터 동기화
GitHub의 Gist에 데이터를 백업/복원합니다. 같은 Token + Gist ID로 모든 기기에서 데이터 공유 가능.
→ 토큰 발급 (gist 권한만 체크)
기존 Gist에 덮어쓰려면 ID 입력 (다른 기기와 공유 시)
💡 사용 방법 (처음 사용 시)
  1. 위 링크에서 GitHub Token 발급 (gist 권한만 체크)
  2. Token 붙여넣기 + ID 비워둔 채 업로드 → 새 Gist 생성됨
  3. 생성된 Gist ID가 자동으로 채워짐
  4. 다른 기기에서 같은 Token + ID 입력 후 다운로드
  5. ✅ 무제한 무료, 비공개 Gist로 안전

📲 핸드폰 앱으로 설치하기

이 앱은 PWA(Progressive Web App)로, 설치하면 일반 앱처럼 홈 화면 아이콘, 전체 화면, 오프라인 사용이 모두 가능합니다.

🤖 안드로이드 (Chrome)

  1. Chrome으로 이 페이지 열기
  2. 우상단 ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
  3. 또는 화면 상단 📲 앱 설치 버튼 누르기

🍎 iOS (Safari)

  1. Safari로 이 페이지 열기 (Chrome 불가)
  2. 하단 공유 버튼 (📤) 누르기
  3. "홈 화면에 추가" 선택
  4. 이름 확인 후 추가

⚡ 오프라인 / 빠른 로딩

설치 후에는 인터넷 없이도 앱이 열립니다. 모든 데이터는 기기에 저장되며 클라우드에 업로드되지 않습니다.

📦 진짜 APK 파일로 만들기 (고급)

1. 모든 파일(index.html, manifest.json, sw.js, icon-*.svg)을 GitHub Pages 등 무료 호스팅에 업로드
2. PWABuilder.com 접속해 호스팅 URL 입력
3. Android Package 다운로드 → APK 파일 생성
